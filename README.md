# Controle de Estoque – Mobile

## Sobre o Projeto

Aplicativo mobile desenvolvido em React Native com Expo para auxiliar no gerenciamento e controle de estoque de produtos.

O aplicativo permite que os usuários acessem o sistema pelo celular e gerenciem informações relacionadas aos produtos cadastrados.

## Tecnologias Utilizadas

- React Native
- Expo
- JavaScript
- Axios
- AsyncStorage
- React Navigation

## Funcionalidades

- Login de usuários.
- Cadastro de usuários.
- Consulta de produtos.
- Gerenciamento do estoque.
- Controle de quantidade.
- Definição de limites de estoque baixo e alerta.
- Integração com API Laravel.

## Como Executar

### 1. Clonar o repositório

```bash
git clone https://github.com/isamartinssenai/mobile.git
```

### 2. Entrar na pasta

```bash
cd mobile/estoque_limpeza
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Iniciar o projeto

```bash
npx expo start
```

## Integração

O aplicativo se comunica com a API Laravel, responsável pelo processamento das informações e pela comunicação com o banco de dados MySQL.

## Objetivo

Oferecer uma maneira prática de acessar e gerenciar o estoque por meio de dispositivos móveis.
